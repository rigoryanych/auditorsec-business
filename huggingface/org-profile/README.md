# Audityzer / AuditorSEC

> AI-powered Web3 security auditing infrastructure — open-source tools, datasets, and models for smart contract analysis.

## What We Build

- **Audityzer** — automated smart contract vulnerability scanner (Solidity, EVM-compatible chains)
- **AuditorSEC** — full-cycle audit platform: AI triage, human review, on-chain reporting
- **Audit Datasets** — labeled vulnerability datasets for training and benchmarking audit models
- **Audit Model Cards** — fine-tuned LLMs and classifiers for reentrancy, overflow, access control bugs
